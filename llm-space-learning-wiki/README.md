# LLM Space 开发者学习课程

> 面向初级开发者和贡献者的完整结构化学习路径，帮助你从零开始掌握 LLM Space 的开发。

## 这是什么？

这是一份**独立、自包含的学习 wiki**，作为单文件 HTML 网站交付。直接在浏览器中打开 `index.html` 即可使用，无需安装依赖或构建步骤。

课程包含 7 个章节、31 节课，从最基础的编程概念（文件、JSON、JS/TS、React、异步编程）开始，逐步深入到 LLM Space 的架构、核心领域逻辑、Agent 运行时、桌面应用、远程运行时，直到 UI 工程和发布实践。

## 面向人群

- **初级开发者** — 想了解如何为 LLM Space 做贡献，但不知道从哪里开始
- **非开发者背景的产品/运营人员** — 想理解项目架构和技术实现
- **新加入团队的成员** — 需要快速上手代码库
- **所有感兴趣的贡献者**

## 课程特性

- 📚 **分级内容** — L0 首页 / L1 章节导览 / L2 详细课程，每节课有前置知识标记和预计时长
- 🎯 **小白友好** — 复杂概念补充外部基础知识解释，不假设你已经熟悉 Electron/Monorepo/Agent 等概念
- 🔍 **内置搜索** — 全站内容即时搜索
- 📊 **进度追踪** — 使用本地存储记录你的学习进度
- 📖 **术语表** — 一键打开技术术语解释
- 📝 **源码查看** — 每节课可以查看对应的原始 Markdown


## 如何使用

### 直接使用（推荐）

在浏览器中打开 `index.html` 即可开始学习，不需要任何其他步骤。

### 从源码重新生成

如果你修改了 `content/` 下的 Markdown，可以重新生成 HTML：

```bash
# 在仓库根目录执行
node llm-space-learning-wiki/scripts/generate-learning-wiki.mjs
```

生成结果会覆盖写入 `index.html`。
