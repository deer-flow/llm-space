# 第零章：零基础预备课

这一章专门服务没有编程经验或刚入门的读者。你不需要先记住所有语法，只需要建立几个能反复使用的心智模型：程序如何保存数据、模块如何协作、异步任务为什么需要等待和取消、界面如何随状态变化，以及 AI Agent 如何在模型与工具之间循环。

## 先选你的起点

| 你的情况 | 建议 |
| --- | --- |
| 没写过代码 | 按顺序完成本章五节，再进入第一章 |
| 写过少量 JavaScript | 快速完成第 1、2、4、5 节 |
| 熟悉前端但不了解 Agent | 重点学习第 4、5 节 |
| 已有项目开发经验 | 用本章作术语表，直接从第一章开始 |

## 本章学习目标

- 看懂变量、对象、数组、函数、模块和 JSON 的基本形式。
- 理解 TypeScript 类型是“开发期检查”，磁盘和网络数据仍需运行时校验。
- 理解 React 组件、Props、State、Context 与 Store 的分工。
- 理解 Promise、异步迭代、HTTP、RPC、SSE 和取消。
- 理解 LLM、Prompt、Token、Tool Call、ReAct、MCP 和 Agent Runtime。

## 学习方法

每节先看图和类比，再运行最小示例。第一次阅读不要求记住 API 名称；当后续源码再次出现这些词时，回来复习对应卡片即可。
